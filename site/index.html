支持哪些服务商和模型

任何兼容 OpenAI 协议的服务都能接入，例如 DeepSeek、Kimi、智谱、Gemini 及各类中转服务，另有 Anthropic 与 Gemini 的原生协议支持。服务商地址、模型列表与密钥全部自定义，可同时配置多家。

我的数据存在哪里

全部在你的设备上。会话与配置保存在本地加密数据库，访问密钥由系统安全存储保管。应用没有账号体系，没有统计埋点，也不运营服务器。

API 密钥从哪里获取

到对应服务商的官方控制台创建，例如 DeepSeek 开放平台、Kimi 开放平台、智谱 AI 开放平台。应用内新建服务商时可直接套用现成模板，填上密钥即可使用。

应用收费吗

应用本身免费。模型 API 的调用费用由你和服务商按用量结算，应用不经手任何费用。
